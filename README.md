#C++ PostgreSQL Network Monitor

Una herramienta desarrollada en **C++** y conectada a **PostgreSQL** mediante la biblioteca nativa `libpq` para realizar sondeos de red automatizados (ICMP/Ping) y registrar el historial de estado de los dispositivos en tiempo real.

##  Tecnologías y Entorno
* **Lenguaje:** C++
* **Base de datos:** PostgreSQL (`libpq` / `psql`)
* **Entorno de desarrollo:** MSYS2 / MinGW64
* **Control de versiones:** Git / GitHub
